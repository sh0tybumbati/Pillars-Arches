# Pillars & Arches 🏛️

A Minecraft resource pack adding decorative pillars and arches for builders.

---

## Overview

Pillars & Arches enhances your Minecraft builds with elegant architectural elements. Perfect for builders who want to add classical and decorative touches to their structures, this resource pack provides a variety of pillar and arch designs compatible with multiple Minecraft versions.

## Features

- 🏛️ **Decorative Pillars**: Multiple styles and designs
- 🌉 **Architectural Arches**: Various arch configurations
- 🎨 **Builder-Friendly**: Designed specifically for creative building
- 🔄 **Multi-Version Support**: Compatible across multiple Minecraft versions

## Compatibility

This resource pack is compatible with the following Minecraft versions:

- ✅ **1.16.2 - 1.16.5**
- ✅ **1.17.x - 1.18.x**
- ✅ **1.19.x - 1.20.x**
- ✅ **1.21.x**

## Installation

### Method 1: Direct Download

1. Download the resource pack `.zip` file from the [Releases page](https://github.com/Sh0tybumbati/Pillars-Arches/releases)
2. Open Minecraft
3. Go to **Options** → **Resource Packs**
4. Click **Open Pack Folder**
5. Move the downloaded `.zip` file into the opened folder
6. Go back to Minecraft and click the **arrow** to activate the pack
7. Click **Done** and enjoy!

### Method 2: Clone Repository

```bash
git clone https://github.com/Sh0tybumbati/Pillars-Arches.git
```

Then follow steps 2-7 from Method 1, using the cloned directory.

## Usage

Once installed and activated:

1. Start a new world or load an existing one
2. Open your inventory or creative menu
3. Browse the available pillar and arch blocks
4. Use them to enhance your architectural designs!

### Building Tips

- Pillars work great for supporting structures and adding vertical interest
- Arches are perfect for doorways, windows, and decorative openings
- Combine different styles to create unique architectural designs
- Use them in combination with vanilla blocks for best results

## Version Compatibility Notes

This pack is designed to work seamlessly across multiple Minecraft versions. If you encounter any issues:

- Make sure you're using a compatible version (see list above)
- Ensure the resource pack is properly activated
- Try reloading resource packs with `F3 + T`
- Check that no conflicting resource packs are active

## Technical Details

### File Structure
```
Pillars-Arches/
├── assets/
│   └── minecraft/
│       ├── textures/    # Block textures
│       ├── models/      # Block models
│       └── blockstates/ # Block state definitions
├── pack.mcmeta          # Pack metadata
└── pack.png             # Pack icon
```

### Supported Versions
The pack includes separate compatibility files for different Minecraft versions:
- Format 6-7: 1.16.2-1.16.5
- Format 7-8: 1.17.x-1.18.x
- Format 9-12: 1.19.x-1.20.x
- Format 13+: 1.21.x
